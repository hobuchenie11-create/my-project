# Шаблоны передачи показаний (для жителей)

> Номер квартиры **обязательно** указывайте в первой строке.

## Для 1-2-комнатных квартир

```
Кв. 12
Эл.эн - 234
хвс - 5
гвс - 101
```

## Для 3-комнатных квартир

```
Кв. 12
Эл.эн –
хвс (кухня) –
хвс (сан.узел) -
гвс (кухня) –
гвс (ванна) -
гвс (итого) -
```

**Важно для 3-комнатных квартир:** записывайте и показания по каждому прибору
ГВС отдельно, и их сумму. Сведения передаются двум ресурсоснабжающим
организациям:
- в **Росводоканал** — показания по 4 счётчикам воды;
- в **ОЭК** — показания ГВС одной цифрой (сумма показаний ГВС на кухне и в
  ванной).

# Словарь распознавания (для разработки)

Бот принимает показания и в свободной форме — модуль `bot/services/parser.py`
понимает распространённые сокращения. Ниже — реальные варианты из чата дома,
на которых построен и протестирован разбор.

| Прибор | Как пишут жители |
|--------|------------------|
| Электроэнергия | `Св`, `Эл.эн`, `Эл. энерг.`, `Эл. Эн.`, `Э/энер`, `Эл/э`, `Электроэнергия`, `Эдектро` (опечатки тоже) |
| ХВС (холодная) | `Хв`, `ХВС`, `Хол`, `Х. В.`, `Х/В`, `Хвс`, `Х. Кух` (одна буква — только рядом с местом установки) |
| ГВС (горячая) | `Гв`, `ГВС`, `Гор`, `Г. В.`, `Г/В`, `Гвс`, `Г. Ван` (одна буква — только рядом с местом установки) |
| Кухня | `кухня`, `кух`, `Кух.` |
| Санузел / ванна | `с/у`, `с/уз`, `сан.узел`, `Сан. Уз.`, `туал`, `ванна`, `ван`, `Ванная` |
| Сумма ГВС | `сумма гв`, `Сумма гвс`, `гвс (итого)`, `Общ. ГВС` |

Разделителем между названием и числом может быть пробел, тире, двоеточие,
точка, слеш или запятая. Принимаются числа с ведущими нулями (`0000076`) и
запятой в дробной части (`123,45`). Строки с газом (`Газ: 276`) распознаются,
но не учитываются (в доме учитываются вода и электроэнергия).

Показания можно писать и в одну строку, перечисляя приборы через запятую или
точку с запятой: `кв38,Х/В30,Г/В 42,Эл/э 15873`. Запятая внутри числа при этом
остаётся дробной частью (`хвс 56,78` — одно показание). Номер квартиры
распознаётся и без пробела: `кв38`, и с лишними разделителями: `Кв,, 29`.

Порядок «показание — прибор» тоже понимается: `11882 - Эл.эн`, `54 - Хвс кухня`.
Оба порядка могут смешаться в одном сообщении.

Подпись и число могут стоять на разных строках — жители пишут и так:

```
КВ.41
ЭЛ.ЭНЕРГИЯ
31560
```

Строка с одним лишь номером квартиры на следующую не переносится: «Кв. 5» и
дальше просто число показанием не считается.

### Перенос пачкой (из WhatsApp)

Председатель копирует из чата WhatsApp несколько сообщений подряд и
отправляет одним текстом. Новое сообщение бот определяет по строке с
номером квартиры, а служебные приписки вида `[19.08.2026, 21:03] Мария:`
и разговоры между показаниями отбрасывает:

```
[19.08.2026, 21:03] Мария Иванова: Кв. 5
Эл.эн 15230
Хвс 123
[19.08.2026, 22:30] Иван: Добрый вечер, соседи!   <- отброшено
[20.08.2026, 08:00] Мария: Кв. 60
Х. Кух-277
```
