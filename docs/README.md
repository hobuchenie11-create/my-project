# Домовед — база знаний дома Магистральная, 2

Статический сайт для жителей. Публикуется через GitHub Pages, открывается на любом
телефоне по обычной ссылке — без регистрации и приложений.

Живёт в публичном репозитории `magistralnaya-2`: содержимое этой папки лежит в его
корне. Настройки публикации: **Settings → Pages → Deploy from a branch → main → / (root)**.

Памятка `spec-schet/` намеренно оставлена самодостаточной — её ссылка уже разослана
жителям, менять там нечего.

## Ежемесячный цикл

Раз в месяц, после получения выписки со специального счёта:

1. Взять из выписки три числа: **оплачено собственниками за месяц**, **начислено
   процентов**, **остаток на счёте** и дату остатка.
2. Добавить новую запись в конец массива `months` в `data.js`:
   ```js
   { period: "2026-07", paid: 0, interest: 0, balance: 0, balanceDate: "2026-07-31" }
   ```
3. Сохранить и закоммитить. Через минуту страница `/vznosy/schet/` показывает новый
   месяц, а предыдущие уходят в таблицу «По месяцам».
4. На странице нажать **«Скачать картинку»** — получится готовое объявление в том же
   виде, что вывешивали раньше. Его можно распечатать для подъезда и отправить в чат
   дома.

Ничего больше править не нужно: заголовок, период и суммы на картинке подставляются
сами.

## Как это будет делать бот

`tools/announcement.py` рисует ровно ту же картинку из командной строки или из кода:

```bash
python3 tools/announcement.py \
  --period 2026-07 --paid 71661.16 --interest 8253.70 \
  --balance 2051123.18 --balance-date 2026-07-31 --out iyul-2026.png
```

```python
from announcement import render
render(period="2026-07", paid=..., interest=..., balance=...,
       balance_date="2026-07-31", out="iyul-2026.png")
```

То есть бот спрашивает три числа → рисует объявление → отправляет в чат дома и
дописывает запись в `data.js` (коммитом через GitHub API). Макет объявления описан
дважды: в `tools/announcement.py` для бота и в `assets/announcement.js` для сайта —
**при изменении дизайна правьте оба файла**, иначе картинки разойдутся.

## Что ещё не заполнено в data.js

Эти поля пока пустые — страницы показывают на их месте прочерк или подсказку:

- `contacts.telegram` — без него не работает кнопка «Заказать акт сверки»
- `account.ownerFull`, `account.bank`, `account.inn` — для шапки заявлений
- `house.city` — город в шапке заявлений
- `house.totalArea`, `account.tariff` — площадь дома и тариф взноса

## Как добавить новый раздел

1. Создайте папку с понятным именем, например `sobranie/`, и файл `index.html`
   внутри (проще всего скопировать `vznosy/index.html` и заменить содержимое).
2. В `index.html` на главной добавьте вкладку в блок `<nav class="tabs">`:
   ```html
   <a class="tab" href="sobranie/">Общее собрание</a>
   ```
3. При необходимости добавьте карточку-ссылку (`<a class="feature">`) и вопросы в
   блок «Частые вопросы» (`<details>` → `<summary>` вопрос → `<div class="body">` ответ).

Чтобы вывести на странице любое значение из `data.js`, достаточно написать:

```html
<span data-dm="account.number"></span>
<span data-dm="months.0.balance" data-fmt="money"></span>
```

Форматы: `money`, `percent`, `date`, `dateShort`, `area`, `tariff`.

## Индексация и приватность

Поиск закрыт в двух местах: `robots.txt` и тег `<meta name="robots" content="noindex,
nofollow">` в каждой странице. Ссылка работает у всех, кому её отправили, но в выдаче
Яндекса и Google страницы не появляются. Захотите открыть — уберите оба.

## Превью в мессенджерах

За картинку и текст при отправке ссылки отвечают теги `og:title`, `og:description`,
`og:image` в `<head>`. Адреса в них абсолютные — при переезде на другой домен их нужно
поменять. Мессенджеры кэшируют превью; для Telegram кэш сбрасывается ботом
[@WebpageBot](https://t.me/WebpageBot).

## Проверка перед публикацией

Тексты памятки, ответов и бланков заявлений подготовлены по скриншотам приложения и
исходным данным о спецсчёте. Шаблоны заявлений типовые — перед рассылкой жителям их
стоит сверить с получателем платежа и советом дома, особенно реквизиты счёта.
