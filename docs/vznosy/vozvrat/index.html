Какие документы приложить

Перечень фонда — что представляют вместе с заявлением о возврате.

Обязательно

  1. Платёжные документы — оригиналы либо копии с предъявлением оригиналов.
  2. Копия паспорта заявителя: 2–3 страница и страница с регистрацией.
  3. Банковские реквизиты для возврата денежных средств.

При необходимости

  1. Копия свидетельства о праве собственности — если дом исключён из региональной программы.
  2. Копия ордера на квартиру, договора социального найма, выписки из муниципальной казны или квитанции за последний месяц по оплате соцнайма — если у нанимателя нет обязанности платить взносы.
  3. Копия договора купли-продажи помещения — если обязанность платить взносы прекратилась.
  4. Доверенность на представление интересов собственника.
  5. Иные документы для подтверждения личности, полномочий и прав на собственность — по требованию сотрудника абонентского отдела фонда.
