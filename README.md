# my-project

Сайт-визитка (`index.html`) со встроенной системой сбора и анализа показателей посещаемости.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Сайт-визитка (одна страница) |
| `analytics.js` | Модуль сбора метрик — подключён на главной странице |
| `analytics.html` | Дашборд: KPI, графики, таблица событий, экспорт |

## Какие показатели собираются

- **Сессии и посетители** — начало сессии (таймаут 30 минут), новый/повторный посетитель, номер визита;
- **Просмотры страницы** — каждое открытие;
- **Просмотры секций** — какие секции страницы реально увидели (IntersectionObserver);
- **Клики** — по кнопкам, меню, контактам и ссылкам, с меткой элемента;
- **Глубина прокрутки** — отметки 25 / 50 / 75 / 90 / 100 %;
- **Время вовлечённости** — только время с видимой вкладкой;
- **Контекст** — тип устройства, экран, язык, referrer, UTM-метки, часовой пояс;
- **Ошибки JS** на странице.

Сбор работает **без cookies и внешних сервисов**: события хранятся в localStorage браузера
(кольцевой буфер на 2000 событий).

## Как посмотреть аналитику

Откройте `analytics.html` в том же браузере, где открывался сайт. Доступны:
выбор периода (7/30 дней/всё время), KPI-плитки, графики визитов, секций,
глубины прокрутки, кликов и устройств, таблица последних событий,
экспорт в JSON/CSV, импорт ранее выгруженного JSON и кнопка «Демо-данные»
для предпросмотра дашборда без реального трафика.

## Отправка на сервер (опционально)

По умолчанию данные никуда не отправляются. Чтобы собирать метрики со всех
посетителей централизованно, задайте endpoint **до** подключения `analytics.js`:

```html
<script>
  window.ANALYTICS_CONFIG = {
    endpoint: 'https://ваш-сервер/collect', // POST JSON: { context, events: [...] }
    debug: false
  };
</script>
<script src="analytics.js" defer></script>
```

События будут отправляться батчами (fetch keepalive / sendBeacon при уходе со страницы).
Формат тела запроса: `{ context: {...}, events: [{ id, name, ts, visitorId, sessionId, props }] }`.

## Приватность

- Персональные данные не собираются, идентификаторы — случайные строки;
- посетитель может отключить сбор для себя: `analytics.optOut()` в консоли
  (вернуть — `analytics.optIn()`);
- очистка собранного: кнопка «Очистить» на дашборде или `analytics.clear()`.

## API

```js
analytics.track('custom_event', { any: 'props' }); // своё событие
analytics.getEvents(); // массив всех сохранённых событий
analytics.clear();     // удалить собранные события
```
