# Алиса — прототип интернет-магазина одежды для новорождённых

Рабочий прототип витрины и оформления заказа: комплекты на выписку из роддома,
комплекты для малыша, ползунки и распашонки, чепчики и шапочки, комбинезоны-слипы,
боди. Без сборщиков и зависимостей — открывается двойным кликом по `index.html`.

## Что уже работает

- **Каталог** — 20 товаров, фильтры по категории, сезону и размеру, поиск по названию,
  ткани и цвету, сортировка по популярности, цене и оценке.
- **Карточка товара** — выбор размера и цвета, состав комплекта, ткань, состав волокон,
  рекомендации по уходу.
- **Избранное** — отметка сердечком, отдельный показ отмеченного.
- **Корзина** — количество, удаление, промокоды (`МАЛЫШ10`, `ВЫПИСКА15`), индикатор
  «сколько осталось до бесплатной доставки».
- **Оформление заказа в 3 шага** — контакты с проверкой телефона и почты, доставка
  (самовывоз, курьер, СДЭК, Почта России) и оплата (карта, СБП, при получении),
  подарочная упаковка, подтверждение с итоговой суммой и номером заказа.
- **Размерная сетка** 50–74 по росту и весу — отдельным разделом и всплывающим окном
  из карточки товара.
- Светлая и тёмная темы, мобильная вёрстка с нижней панелью как в приложении.
- Корзина и избранное сохраняются в браузере и переживают перезагрузку страницы.

Оплата не проводится: заказ сохраняется только в браузере покупателя.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы |
| `assets/css/styles.css` | Стили, цветовые токены, светлая и тёмная темы |
| `assets/js/data.js` | **Все данные: название магазина, контакты, товары, цены, доставка, промокоды** |
| `assets/js/app.js` | Логика: фильтры, корзина, оформление заказа |
| `build.js` | Собирает всё в один файл `dist/alisa.html` для публикации |

## Как поменять содержимое

Почти всё правится в `assets/js/data.js`, разметку трогать не нужно.

**Название, телефон, адрес** — объект `BRAND` в начале файла.

**Логотип.** Пока рисуется временный знак. Когда будет готовый файл:

1. положите его в `assets/img/logo.svg` (подойдёт и `.png`);
2. в `data.js` в объект `BRAND` добавьте строку `logo: 'assets/img/logo.svg',`.

Логотип подставится и в шапку, и в подвал.

**Товары** — массив `PRODUCTS`. Поля одного товара:

```js
{
  id: 'v-05',                      // уникальный код
  name: 'Комплект на выписку …',
  cat: 'vypiska',                  // id из CATEGORIES
  season: 'zima',                  // leto | demi | zima | vsesezon
  price: 8900, oldPrice: 10500,    // oldPrice: null, если скидки нет
  art: 'envelope', tone: '#EDE6DC',// рисунок на карточке и его цвет
  sizes: ['56', '62'],
  colors: ['Молочный', 'Пудровый'],
  material: 'Плащёвка, утеплитель 300 г/м²',
  composition: '100% хлопок',
  care: 'Стирка 30 °C',
  rating: 4.9, reviews: 64,
  badge: 'Хит',                    // 'Хит' | 'Новинка' | null
  desc: 'Описание для карточки товара.',
  includes: ['Конверт-одеяло', 'Шапочка'],  // состав комплекта, [] для одиночных вещей
}
```

Значения `art`: `envelope`, `set`, `pants`, `shirt`, `bonnet`, `romper`, `bodysuit`.
Когда появятся фотографии товаров, рисунки заменяются на `<img>` в функции `art()`
в `app.js` — остальная разметка не меняется.

**Цены доставки** — массив `DELIVERY`, **промокоды** — объект `PROMOS`,
**вопросы и ответы** — `FAQ`, **отзывы** — `REVIEWS`.

## Публикация одним файлом

```bash
node build.js
```

Собирает `dist/alisa.html` — один самодостаточный файл со встроенными стилями
и скриптами. Его можно отправить по почте, открыть с флешки или выложить на любой
хостинг.

## Что нужно добавить для настоящего магазина

Прототип работает целиком в браузере. Для запуска потребуются:
приём заказов на сервере вместо `localStorage`, платёжный шлюз (ЮKassa, Тинькофф),
учёт остатков по размерам и цветам, фотографии товаров, договор оферты и политика
обработки персональных данных.
