# DH OS — «Дом в гармонии»

Версия 0.1.0 Alpha · Статус: разработка

Система автоматического сбора показаний приборов учета воды и электроэнергии
для многоквартирного дома: Telegram-бот принимает показания от жителей
(в личных сообщениях или в общем чате дома), хранит их в базе данных и
формирует для председателя печатную ведомость в Excel.

## Возможности

- 🏠 Передача показаний в диалоге с ботом — бот по очереди опрашивает все
  приборы квартиры.
- 🏢 Набор приборов у каждой квартиры свой — по количеству счетчиков ХВС и
  ГВС из справочника (один счетчик → общий прибор, два → раздельно по кухне и
  санузлу). ХВС и ГВС учитываются независимо, поэтому поддержан и смешанный
  случай (например, один ХВС при раздельном ГВС). Электросчетчик у всех один.
- 💬 Прием показаний из общего чата дома — бот распознает сообщения в
  свободной форме по реальному словарю сокращений жителей: `Св/Эл.эн/Э/энер`,
  `Хв/ХВС/Хол`, `Гв/ГВС/Гор`, `с/у, туал, ванна`, разделители — пробел, тире,
  двоеточие, запятая; ведущие нули и «сумма ГВС» тоже понимаются
  (см. [docs/templates.md](docs/templates.md)).
- 🗓 Регламент сбора: показания принимаются с 15 по 19 число, 20 числа в
  10:00 автоматически формируется ведомость со всеми собранными показаниями.
  С 20 по 30 число показания тоже принимаются — они записываются в строке
  своей квартиры за текущий месяц с пометкой «Переданы после срока сбора
  показаний», а житель получает сообщение, что они будут учтены в следующем
  расчётном периоде (и напоминание о передаче при оплате квитанции или через
  личный кабинет ресурсоснабжающей организации).
- ✅ Проверка показаний (Этап 4): только цифры, не меньше предыдущих,
  предупреждение при расходе воды более 100 м³ за месяц, сверка суммы ГВС.
- 🧾 Квитанция-подтверждение после каждой передачи (Этап 5).
- 📄 Ведомость для ресурсоснабжающих организаций — по утвержденной печатной
  форме, квартиры строго по порядку 1–80, затем нежилые помещения и
  общедомовой прибор. Лист подготовлен к печати: А4, вписан по ширине,
  шапка повторяется на каждой странице.
- 📕 Ведомость непередавших — формируется автоматически 20 числа в 09:00
  (настраивается через `DEBTORS_DAY` / `DEBTORS_HOUR`) и отправляется
  председателю; можно получить в любой момент кнопкой в меню.
- 📗 Книга Excel «Модуль "Сбор показаний"» — 6 листов: ведомость для
  ресурсников, реестр квартир, переданные показания (история), текущие
  показания, контроль передачи (панель председателя) и настройки. Единая цветовая схема DH OS,
  автофильтры, закрепленные шапки, выпадающие списки, защита служебных
  столбцов. Собирается из базы по кнопке — открывать и править её можно
  свободно, на работу бота это не влияет.
- 🛠 Меню председателя: реестр, статистика, список должников, ручная
  рассылка напоминаний, пользователи, выгрузка ведомости, резервная копия.
- 🗂 Задачи председателя: годовой цикл регулярных дел — выписка из банка по
  спецсчёту (2-5 числа), разноска платежей и печать квитанций (5-10),
  поступление аренды за нежилое помещение (до 10, с суммой и датой),
  оплата коммунальных услуг по нежилому помещению (до 18, с суммой и датой —
  помечена как важная), передача показаний ресурсникам (20-25). Статусы,
  подсветка за 3 дня до срока, ежедневные напоминания, отдельная вкладка
  «Мои задачи» для разовых дел с автоматическим отсчётом срока, годовой план
  в Excel и информационная сводка для Совета дома. Цикл продолжается в
  следующем году автоматически.
- 🔧 Поверка общедомовых приборов (тепло, ГВС, ХВС): у каждого прибора свой
  межповерочный интервал (по умолчанию 4 года) и своя дата последней поверки.
  Срок следующей считается сам, за полгода до него появляется задача с
  напоминаниями. После внесения проведённой поверки срок сдвигается на
  следующий цикл, история поверок сохраняется.
- 🔔 Автоматические напоминания должникам по дням месяца (Этап 7,
  по умолчанию 17, 23, 25 — настраивается в `.env`).
- 📝 Журнал действий и логи.

## Быстрый старт

Нужен Python 3.11+.

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать файл настроек
cp .env.example .env
# и вписать в .env:
#   BOT_TOKEN  — токен бота от @BotFather
#   ADMIN_IDS  — Telegram ID председателя (узнать: @userinfobot)

# 3. Запустить
python run.py
```

При первом запуске автоматически создается база данных `database/dhos.db`.
Если рядом лежит заполненный справочник `data/apartments.xlsx`, набор
приборов по каждой квартире берется из него; иначе создается временный
реестр из одинаковых квартир, который можно уточнить импортом справочника.

В VS Code: открыть папку проекта → F5 (конфигурация «DH OS: запустить бота»).

### Справочник квартир

Реальный набор счетчиков задается в `data/apartments.xlsx`, лист
«Справочник квартир»:

| № квартиры | Тип квартиры | Кол-во ХВС | Кол-во ГВС | Эл-во |
|-----------|--------------|-----------|-----------|-------|

Набор приборов определяется числом счетчиков ХВС и ГВС (независимо друг от
друга). Файл применяется автоматически при старте бота, либо вручную:
`python -m excel.import_registry`.

### Подключение к общему чату дома

1. Добавить бота в групповой чат.
2. Выключить у бота режим приватности (@BotFather → Bot Settings →
   Group Privacy → Turn off), чтобы он видел сообщения.
3. При желании указать `GROUP_CHAT_ID` в `.env`, чтобы бот принимал
   показания только из этого чата.

## Полезные команды

```bash
python -m reports.monthly_statement 2026-07   # ведомость за период в Excel
python -m reports.print_statement             # ведомость в консоли
python -m database.backup                     # резервная копия базы
python -m excel.import_registry --template    # шаблон реестра квартир (xlsx)
python -m excel.import_registry               # импорт реестра из data/apartments.xlsx
pytest                                        # тесты
```

## Структура проекта

```
DH_OS/
├── bot/                  # Telegram-бот (aiogram 3)
│   ├── main.py           # сборка и запуск бота
│   ├── config.py         # настройки из .env
│   ├── handlers/         # обработчики: старт, регистрация, показания,
│   │                     # отчеты, админ-меню, общий чат

│   ├── states/           # FSM-состояния сценариев

│   │                     # показания, ведомость, напоминания

│   └── utils/logger.py   # логирование в logs/
├── database/             # SQLite: схема, репозиторий, инициализация, бэкап
├── excel/                # экспорт ведомости, импорт реестра квартир
├── reports/              # формирование месячной ведомости
├── docs/templates.md     # шаблоны для жителей и словарь распознавания
├── data/                 # реестр квартир (apartments.xlsx)
├── logs/  backups/       # логи и резервные копии

└── run.py                # точка входа
```

## Ведомость

Формируется автоматически по утвержденной форме:

| Кв. | ✔ | Электроэнергия | ГВС сумма | ХВС кухня | ХВС сан.узел | ГВС кухня | ГВС ванна | Примечание |
|-----|---|----------------|-----------|-----------|--------------|-----------|-----------|------------|

«ГВС сумма» считается автоматически (кухня + ванна). Нежилые помещения —
отдельными строками (ХВС/ГВС). Строка «Общедомовой прибор учета»
заполняется вручную.
