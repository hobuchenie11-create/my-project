# Копилка класса

Прототип мобильного приложения для учёта сборов родительского комитета: кто сдал, кто нет,
сколько собрано и до какого числа нужно сдать.

Открыть: `index.html` — один файл, без установки и без интернета.

## Что умеет

**Две роли** — переключаются в шапке:

- **Казначей** — видит полный список класса по каждому сбору, отмечает поступления в один тап,
  подтверждает переводы, создаёт сборы, копирует готовое напоминание для чата.
- **Родитель** — видит только свою сумму, срок и статус, отмечает «Я перевела»;
  казначей подтверждает поступление.

**Категории сборов** (нижнее меню):

| Вкладка | Поводы |
|---|---|
| Подарки детям | Новый год · 23 февраля · 8 марта |
| Подарки учителям | День рождения · День учителя · Новый год · 8 марта · Выпускной |
| Ремонт класса | Ремонт и оснащение |
| Питание детей | Питание (помесячно) |

**Список класса** — 29 строк: 24 ученика и 5 свободных мест в запасе для новых.
Свободные места видны в каждом сборе и заполняются на вкладке «Список класса» (иконка ⚙).
Новый ученик сразу попадает во все расчёты.

**Предельный срок сдачи считается автоматически:** дата начала сбора + срок в днях.
Дата пересчитывается прямо в форме при вводе. На карточке показывается,
сколько дней осталось; за 3 дня до срока карточка становится янтарной,
после срока — розовой с числом дней просрочки.

**Итоги** — на каждом уровне: по сбору (сдали N из 29, собрано X из Y, процент),
по категории и по классу целиком на вкладке «Обзор».

## Данные

Всё хранится локально в браузере (localStorage) — деньги через приложение не проходят,
это учётный инструмент. Кнопка «Скопировать отчёт» на вкладке «Список класса» выгружает
сводку по всем сборам текстом, «Напомнить» — список не сдавших для отправки в чат.
Сбросить к демо-примеру можно там же.
