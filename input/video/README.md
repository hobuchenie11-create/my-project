# Папка для видео

Сюда кладутся видеофайлы, которые нужно смонтировать.

## Как загрузить через сайт GitHub

1. Открыть эту папку на GitHub, на рабочей ветке.
2. Кнопка **Add file** → **Upload files**.
3. Перетащить видеофайл в окно браузера.
4. Внизу нажать **Commit changes**.

## Запуск

```bash
./automontage input/video/запись.mp4
./automontage input/video/запись.mp4 --target 45 --title "Название"
```

## Ограничение по размеру — прочитать до загрузки

Через сайт GitHub можно загрузить файл **не больше 25 МБ**. Через командную
строку — до 100 МБ. Видео с телефона почти всегда больше: минута записи в 4K
весит 200–350 МБ.

Проверить размер:

```bash
ls -lh видео.mp4
```

Если файл не проходит, сожмите его перед загрузкой — для подбора настроек
качества 720p достаточно:

```bash
ffmpeg -i исходник.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -preset fast \
       -c:a aac -b:a 128k сжатое.mp4
```

Взять только первые две минуты:

```bash
ffmpeg -i исходник.mp4 -t 120 -c copy кусок.mp4
```

Для настоящего монтажа длинной записи загружать ничего не надо — разверните
движок у себя (`./setup.sh`) и работайте с файлом локально. Так быстрее, и
ограничений по размеру нет.

## Что важно для монтажа

Монтаж строится на **речи**: паузы между фразами становятся точками реза.
Поэтому нужна звуковая дорожка с речью. Видео без звука или с одной музыкой
конвейер не разрежет — оставит одним куском.

Форматы: mp4, mov, mkv, avi, webm — всё, что читает ffmpeg.
