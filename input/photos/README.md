# Папка для фото

Сюда кладутся фотографии, из которых нужно собрать видео.

## Как загрузить через сайт GitHub

1. Открыть эту папку на GitHub, на рабочей ветке.
2. Кнопка **Add file** → **Upload files**.
3. Перетащить фотографии в окно браузера.
4. Внизу нажать **Commit changes**.

После этого фотографии видны в репозитории, и монтаж можно запускать.

## Как загрузить через командную строку

```bash
git checkout claude/auto-video-editing-engine-m29h4t
cp ~/Desktop/мои-фото/*.jpg input/photos/
git add input/photos/
git commit -m "Add photos for montage"
git push
```

## Запуск

```bash
./autophotos input/photos --order date --title "Название"
./autophotos input/photos --style collage --music track.mp3
```

## О чём стоит знать

**Размер.** Git плохо переносит большие бинарные файлы. Для подбора настроек
достаточно 10–30 снимков. Полный архив на сотни фотографий сюда загружать не
надо — его лучше смонтировать у себя на компьютере, где папка с фото лежит
локально и никуда не загружается.

**Приватность.** Всё, что попало в git, остаётся в истории репозитория даже
после удаления файла. Личные снимки лучше монтировать локально.

**Формат.** jpg, png, webp, bmp, tif и heic. Фотографии с iPhone в формате HEIC
конвертируются автоматически. Чтобы телефон сразу снимал в JPEG:
Настройки → Камера → Форматы → «Наиболее совместимые».

**Порядок кадров.** По умолчанию — по имени файла. `--order date` берёт дату
съёмки из EXIF, что обычно правильнее для архива.
