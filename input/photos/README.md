# Папка для фото

**Для монтажа у себя на компьютере эта папка не нужна.**

Если движок установлен на вашей машине, просто укажите команде путь к любой
своей папке — копировать файлы сюда не надо:

```bash
cd ~/my-project
./autophotos /mnt/c/Users/ИМЯ/Pictures/Монтаж --limit 5 --title "Проба"
```

Где `ИМЯ` — ваша папка пользователя в Windows. Проверить путь заранее:

```bash
ls /mnt/c/Users/ИМЯ/Pictures/Монтаж
```

Если вывелся список файлов — путь верный.

---

## Зачем тогда эта папка

Только для одного: **показать фотографии Claude**, чтобы он посмотрел на них и
помог подобрать длительность кадра, раскладку коллажа или порядок снимков.

Для собственного монтажа она не используется.

## Как положить сюда фото для показа

Через сайт GitHub:

1. Открыть эту папку на GitHub, на рабочей ветке.
2. **Add file** → **Upload files**.
3. Перетащить снимки в окно браузера.
4. Внизу **Commit changes**.

Или из командной строки:

```bash
cd ~/my-project
cp /mnt/c/Users/ИМЯ/Pictures/Монтаж/*.jpg input/photos/
git add input/photos/
git commit -m "Фото для подбора настроек"
git push
```

## О чём стоит знать

**Это публичный репозиторий.** Всё загруженное видно кому угодно и остаётся в
истории даже после удаления файла. Личные и семейные снимки сюда класть не
стоит — монтируйте их у себя, там они никуда не уходят.

**Размер.** Через сайт GitHub проходит файл не больше 25 МБ. Десяти–тридцати
снимков достаточно, чтобы подобрать вид.

**Папка изначально пустая** — здесь лежит только эта инструкция. Для проверки
установки есть готовые снимки в `samples/demo`:

```bash
./autophotos samples/demo --title "Проверка"
```
