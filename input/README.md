# Папка для исходников

**Для монтажа у себя на компьютере эта папка не нужна.** Указывайте командам
путь к своим файлам напрямую:

```bash
cd ~/my-project
./autophotos /mnt/c/Users/ИМЯ/Pictures/Монтаж --limit 5 --title "Проба"
./automontage /mnt/c/Users/ИМЯ/Videos/запись.mp4 --target 60
```

Готовые ролики складываются в папку `output/`. Открыть её в проводнике Windows:

```bash
explorer.exe output
```

---

## Зачем тогда эта папка

Только чтобы **показать материал Claude** — если нужно, чтобы он посмотрел на
ваши фото или видео и помог подобрать настройки.

| Папка | Что класть |
|---|---|
| [`photos/`](photos/) | фотографии |
| [`video/`](video/) | видеофайлы |

В каждой лежит инструкция по загрузке.

## Важно

Репозиторий публичный: всё загруженное сюда видно кому угодно и остаётся в
истории даже после удаления. Личные снимки и записи монтируйте у себя —
загружать их никуда не нужно.
