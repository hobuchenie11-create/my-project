# Папка для исходников

Сюда загружаются материалы для монтажа.

| Папка | Что класть | Чем монтировать |
|---|---|---|
| [`photos/`](photos/) | фотографии | `./autophotos input/photos` |
| [`video/`](video/) | видеофайлы | `./automontage input/video/файл.mp4` |

В каждой папке лежит инструкция по загрузке.

Готовые ролики складываются в папку `output/` — там же рядом с каждым видео
лежит JSON с настройками, по которым оно собрано.

## Коротко про объём

Папки рассчитаны на небольшие партии — 10–30 фотографий или короткий
видеофрагмент, чтобы подобрать вид и настройки.

Личный архив и длинные записи загружать сюда не нужно: git плохо работает с
большими файлами, а всё попавшее в репозиторий остаётся в его истории даже
после удаления файла. Для таких задач разверните движок у себя (`./setup.sh`) —
материалы останутся на вашем компьютере.
