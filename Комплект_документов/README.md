# Комплект документов к договору подряда № 1

Пошив народных сценических костюмов для фольклорно-этнографического объединения «Врабий» Любино-Старожильского клуба.

**Заказчик:** БУ «Центр культуры и искусства Любинского района» (БУ «ЦКИ ЛР»)
**Исполнитель:** Масри П.С. (самозанятая, НПД)

## Состав комплекта

| Файл | Документ | Статус в договоре |
|---|---|---|
| 01 | Договор подряда № 1 | основной документ |
| 02 | Спецификация заказа (36 изделий) | Приложение № 1 |
| 03 | Ведомость передачи материалов | Приложение № 2 |
| 04 | Акт сдачи-приёмки выполненных работ | Приложение № 4 (форма) |
| 05 | Таблица размеров участников | Приложение № 3 |
| 06 | Расписка о получении материалов | Приложение № 5 (форма) |
| 07 | Чек-лист приёмки народных костюмов | Приложение № 6 (форма) |

## Порядок использования

1. **При заключении договора** — заполнить и подписать: договор (01), спецификацию (02), таблицу размеров (05).
2. **При передаче материалов** — заполнить ведомость (03), исполнитель оформляет расписку (06).
3. **При приёмке готовых изделий** — заказчик проверяет изделия по чек-листу (07), стороны подписывают акт (04).

В спецификации сохранены все наименования и количества из исходного файла: 36 изделий (порты мужские — 4, рубахи мужские — 4, блузы женские — 7, юбки женские — 7, подъюбники женские — 7, фартуки женские — 7).
