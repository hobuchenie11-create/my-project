# Квитанция на взнос за капитальный ремонт (специальный счёт МКД)

Шаблон платёжного документа для дома по адресу **г. Омск, ул. Магистральная, 2**.
Владелец специального счёта — Региональный фонд капитального ремонта
многоквартирных домов Омской области.

Бланк рассчитан на встраивание в уже существующую книгу разноски с макросом:
все суммы подтягиваются формулами по лицевому счёту, печать идёт чёрно-белой
на А4, а выгрузка в PDF — цветной.

## Что в папке

| Файл | Назначение |
|---|---|
| `output/Квитанция_КапРемонт_Омск_шаблон.xlsx` | Рабочий шаблон. Сохранён в чёрно-белой схеме — готов к печати |
| `output/Образец_печать_ЧБ.pdf` | Как выглядит бумажная квитанция |
| `output/Образец_PDF_цветной.pdf` | Как выглядит квитанция, отправленная жителю по электронной почте |
| `output/Предпросмотр_цветной.xlsx` | Та же книга в цветной схеме — на случай, если понадобится посмотреть в Excel |
| `vba/modКвитанция.bas` | Модуль макросов: подстановка сумм, печать, экспорт PDF, строка QR |
| `build_receipt_template.py` | Генератор шаблона (правки в бланк удобнее вносить здесь и пересобирать) |

## Листы книги

* **КВИТАНЦИЯ** — печатная форма. Одна страница А4, поля 5 мм, вписана
  по ширине и высоте. Единственная ячейка для ввода — `C14` (лицевой счёт,
  имя `КВ_ЛС`), остальное считают формулы.
* **ДАННЫЕ** — приёмник разноски, по одной строке на лицевой счёт за период.
  Ключ поиска — столбец A.
* **НАСТРОЙКИ** — реквизиты специального счёта, расчётный период, срок оплаты
  и строка платежа по ГОСТ Р 56042-2014.
* **СХЕМА** — скрытая таблица «диапазон → цвета ЧБ / ЦВЕТ». По ней макрос
  перекрашивает бланк. Цвета правятся прямо в таблице, код трогать не нужно.
* **ИНСТРУКЦИЯ** — та же памятка, что и здесь, внутри книги.

## Встраивание в книгу разноски

1. Скопировать в свою книгу листы **КВИТАНЦИЯ**, **ДАННЫЕ**, **НАСТРОЙКИ**,
   **СХЕМА** (правый клик по ярлыку → Переместить/скопировать). Именованные
   диапазоны переезжают вместе с листами.
2. `Alt+F11` → *File* → *Import File* → `vba/modКвитанция.bas`.
   Книгу сохранить как `.xlsm`.
3. Подать данные на лист **ДАННЫЕ**. Два равноправных способа:
   * макрос разноски пишет строки сам — вызовами `ПодставитьСуммы`,
     `ПодставитьПлательщика`, `ПодставитьПериод`;
   * либо в столбцах листа ДАННЫЕ проставляются обычные формулы-ссылки
     (ВПР / ИНДЕКС+ПОИСКПОЗ) на тот лист, где разноска уже ведётся —
     переносить данные физически не нужно.

## Автоподстановка сумм

```vb
' Начислено / долг / пени / перерасчёт; итог посчитается сам,
' если не передать его явно
ПодставитьСуммы 31202, Начислено:=674.99, Долг:=19501.38, _
                       Пени:=0, Перерасчет:=0, Оплачено:=13441.28

' Показать бланк по лицевому счёту
СформироватьКвитанцию 31202
```

`ИТОГО К ОПЛАТЕ` берётся из столбца K листа ДАННЫЕ. Если столбец пуст, бланк
считает итог сам: начислено + долг + пени + перерасчёт.

## Печать и PDF

| Макрос | Что делает |
|---|---|
| `ПечатьКвитанции` | Переключает бланк в ч/б, печатает А4, возвращает прежний вид |
| `ЭкспортPDF` | Цветной PDF по текущему лицевому счёту |
| `ПакетныйЭкспортPDF` | Цветные PDF по всем лицевым счетам листа ДАННЫЕ |
| `СхемаЧБ` / `СхемаЦвет` | Переключить оформление вручную |

Обе процедуры печати и экспорта восстанавливают исходную схему, так что книга
всегда остаётся в том виде, в каком её оставили: бумага — чёрно-белая,
электронная копия — цветная.

Имя файла при экспорте: `КР_Июль-2026_л-с-31202_кв-49.pdf`.

## QR-код

Строка платежа по **ГОСТ Р 56042-2014** (формат `ST00012`) собирается формулой
на листе НАСТРОЙКИ (имя `КВ_QR`) и обновляется вместе с суммой. Из VBA её
возвращает функция `СтрокаQR`.

Сама картинка QR в шаблон не встроена — генератора QR в Excel нет. В бланке
оставлено место `G33:H38` и процедура-заготовка `ВставитьQR`, которая
подставляет туда готовый PNG. Без картинки бланк остаётся корректным:
все реквизиты для оплаты напечатаны текстом.

## Что проверить перед первой выдачей квитанций

* **Размер взноса, руб./м².** В исходном файле он подтягивался из внешней
  книги (`'[1]Формирование акта, коэффициент'!B5`), поэтому столбец F листа
  ДАННЫЕ оставлен пустым, а бланк восстанавливает тариф как
  начислено ÷ площадь (для примера из образца выходит 10,70 руб./м²).
  Впишите утверждённый тариф, чтобы в квитанции стояла точная величина.
* **Остаток средств на специальном счёте** и накопления по лицевому счёту
  (столбцы M и N). Пока они пусты, в разделе 4 стоит прочерк. Для спецсчёта
  эти сведения предоставляются собственникам по ч. 7 ст. 177 ЖК РФ —
  их стоит заполнять.
* **Реквизиты** на листе НАСТРОЙКИ перенесены из образца без изменений.

## Пересборка шаблона

```bash
pip install openpyxl
python3 build_receipt_template.py                # рабочий шаблон (ЧБ)
python3 build_receipt_template.py --scheme ЦВЕТ  # цветной предпросмотр
```

Скрипт — источник истины по вёрстке: правки в бланк вносятся в нём, лист
СХЕМА и именованные диапазоны пересобираются автоматически.
