# Домовед — демо-ролик

Демонстрация работы системы для старшего по дому и председателя: приём
показаний, ведомость, реестр ОЭК, панель председателя, ответы жителям.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `index.html` | Весь ролик в одном файле — 10 сцен, титры, главы, музыка. Открывается двойным щелчком, ничего устанавливать не надо. |
| `muzyka-fank-3-36.wav` | Звуковая дорожка ровно на длину ролика — для монтажа MP4. |

## Как показать

Открыть `index.html` в браузере и нажать «Смотреть демо». Интернет нужен
только для шрифтов Golos Text и Unbounded; без него подставятся системные,
вёрстка не поедет. На телефоне ролик просит повернуть экран горизонтально.

Управление: пробел — пауза, стрелки — сцена назад и вперёд, `F` — полный
экран, `M` — музыка. Работают и русские раскладки этих клавиш.

## Длительность

Ролик идёт **216 секунд (3:36)**. Длина складывается из `data-dur` десяти
сцен: 9 + 18 + 30 + 26 + 26 + 26 + 28 + 24 + 16 + 13. Если менять
длительность сцены, дорожку нужно пересобрать под новую сумму.

## Музыка

Музыки как файла в плеере нет — она синтезируется в браузере через Web Audio
при каждом показе. Внешние аудиофайлы страница загрузить не может, поэтому
ритм-секция и саксофон собраны из осцилляторов и шума в блоке `const music`.

Саксофонный фанк: 116 ударов в минуту, круг Fmaj9 · G6/9 · Em7 · Am7 · Dm9 ·
G7sus · Cmaj9 · C7. Круг длится 33,1 с и состоит из двух восьмитактов —
первый сдержаннее, второй в полную силу.

`muzyka-fank-3-36.wav` — та же музыка, отрендеренная офлайн: 44,1 кГц, моно,
16 бит, нормализована до −1 dBFS, вход 1,5 с, уход 4 с. Барабаны и призвук
дыхания строятся на случайном шуме, поэтому два рендера одной композиции
никогда не совпадают побайтно.

Пересобрать дорожку можно из самой страницы:

```js
await window.DomovedDemo.music.renderBuffer(216)   // вернёт AudioBuffer
```

## Данные в ролике

Демонстрационные, по условному дому на 96 квартир. Об этом сказано прямо в
двух сценах — во второй и в итоговой.
